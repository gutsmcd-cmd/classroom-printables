# 教室プリント工房 / Classroom Printables

One app for printable classroom sheets, ready for A4, with answer keys:

- Word search · Crossword (auto-layout from "word - clue" lines) · Word scramble · Matching
- Colouring sheet from a photo · Photo jigsaw (print and cut, or play on screen) · Dot to dot (shapes or a simple photo)
- Mazes · Bingo cards (each card shuffled, pick how many) · Handwriting tracing · Easy sudoku (4×4, 6×6, 9×9)

Free, no ads, no login, works offline. Japanese / English. Part of the [free apps collection](https://gutsmcd-cmd.github.io/free-apps/).

**Live:** https://gutsmcd-cmd.github.io/classroom-printables/

Vite + TypeScript PWA. Bundles Andika Bold (SIL OFL 1.1, see OFL.txt); uses ABC Print instead when installed. Built to the `gh-pages` branch by GitHub Actions.
